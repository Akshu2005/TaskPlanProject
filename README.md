===============================
TEAM TASK MANAGER (FULL-STACK)
==============================

## 📌 Project Overview:

Team Task Manager is a full-stack web application designed to help teams efficiently manage projects, assign tasks, and track progress. It includes role-based access control, authentication, and a dashboard for monitoring tasks.

This project demonstrates real-world application development using modern web technologies.

---

LIVE LINK : https://task-plan-project.vercel.app/

## 🚀 Key Features:

🔐 Authentication:

* User Signup and Login
* Secure password handling
* Session-based authentication

👥 Role-Based Access:

* Admin:
  • Create and manage projects
  • Add/remove team members
  • Assign tasks
  • View all tasks
* Member:
  • View assigned projects
  • Update task status

📁 Project Management:

* Create new projects
* Add team members
* View project list
* Manage project details

✅ Task Management:

* Create tasks within projects
* Assign tasks to users
* Track task status:
  • To Do
  • In Progress
  • Done
* Set deadlines for tasks

📊 Dashboard:

* Total tasks count
* Completed tasks
* Pending tasks
* Overdue tasks
* Task status visualization

## ⚙️ Installation & Setup:

1. Clone the Repository:
   git clone https://github.com/Akshu2005/TaskPlanProject.git

2. Navigate to Project Folder:
   cd TaskPlanProject

3. Install Dependencies:
   npm install

4. Configure Environment Variables:
   Create a .env file and add:
   PORT=5000
   DATABASE_URL=your_database_url
   JWT_SECRET=your_secret_key

5. Run the Application:
   npm run dev
